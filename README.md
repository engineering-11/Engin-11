# Engineering 11

UC Berkeley course: a hands-on introduction to radiation detection and our radioactive world. The course covers basic concepts in radiation detection and radioactivity, electrical circuits, and data analytics, organized around the development of a portable Raspberry Pi-based radiation and environmental sensor system.

The course site is published from this repo via GitHub Pages: <https://engineering-11.github.io/Engin-11/>

## Repository layout

- `index.html` — main course site (syllabus, class schedule, grading, materials)
- `device_project_details.html` — sensor system development tasks
- `final_project_details.html` — final group project options
- `Lessons/` — Jupyter notebooks and slide decks used in lecture
- `Images/` — figures referenced from the lecture notebooks

## Related repositories

These sister repos in the [`engineering-11`](https://github.com/engineering-11) GitHub organization hold the assignment materials referenced from the course site:

- [`Homework-templates`](https://github.com/engineering-11/Homework-templates) — homework and lab notebook templates and solutions
