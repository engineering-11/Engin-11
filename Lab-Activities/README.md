# Lab-Activities

Reference notebooks for the in-class **lab** portion of Engineering 11.

The version of each lab notebook used in class is built up live with students; the version here is the post-class instructor reference for what each lab should cover and how it should run. Lecture-side reference notebooks live in [`Lessons/`](../Lessons/).

Notebooks will be added here as material is migrated. Older (2019–2024) lab notebooks are preserved in the [`Activities`](https://github.com/engineering-11/Activities) archive.

Lab and homework *assignment* templates (the work students complete on their own) live in [`Homework-templates`](https://github.com/engineering-11/Homework-templates).
